# Storage Redirect X v1.2.59

## 模块更新

### 修复了什么问题

- 修复媒体保存链的路径归属与保存结果不一致问题，MediaStore 写入、系统代写进程写入、待提交（pending）文件最终化以及跨设备文件落盘都按重定向后的实际路径完成。
- 修复 scoped FUSE 的真实后端锚点、写入权限与文件提交语义，应用保存、原子替换和覆盖已有文件不再失败。
- 修复路径映射与放行规则的优先级判定，映射优先于宽泛放行，通配符放行与规则级 FUSE 按预期生效，规则路径匹配忽略大小写。
- 修复只读排除目录的权限表现，父目录保持真实只读，子目录与真实后端保持可写，排除路径不会污染上层目录权限。
- 修复映射视图的可见性与隔离，映射目标与真实后端互不串扰，公共映射文件可跨应用读取，映射目标不再指向私有目录。
- 修复多用户环境下的配置归一化与路径处理，运行时存储别名不再遮蔽私有后端。
- 修复文件监视的采集与归因，监视开关严格生效，挂载更新后自动重建监视，延迟关闭的写入和覆盖写操作都会被记录，重复事件按同一次操作合并。
- 修复挂载链路的稳定性问题，守护进程熔断、挂载子进程卡死、公共存储挂载阻塞扩散以及新装应用首启拖慢系统存储的情况不再影响重定向生效。
- 修复 Android 16 上 Java hook 引发的系统进程崩溃，监控相关场景下不再对 MediaProvider 安装 Java hook。
- 修复普通应用被安装写入 hook 的问题，普通应用只经由挂载命名空间与 FUSE 路径生效。
- 修复跨应用私有 SQLite 数据库及其 sidecar 文件的访问与加载失败问题。
- 修复重定向后公共目录残留空目录，以及仅沙盒路径场景下多创建公共叶子目录的问题。
- 降低 MediaProvider 热路径开销，读目录与匿名探测不再造成明显阻塞。

### 增加了什么功能

- 新增新装应用自动重定向，安装完成后按模板自动完成配置。
- 新增 WebUI 备份还原，可导出与导入完整配置。
- 新增 WebUI 运行时控制，可直接开关运行时能力并立即生效。
- 新增管理界面缩放，可调整整体显示比例。

### 功能变化

- 概览页的生效次数改为按运行时实际生效语义统计，并在每次进入时刷新。
- 文件监视过滤支持按应用与操作分别配置，规则按字母序展示，监视记录可直接跳转到对应应用配置。

### 新功能怎么使用

- 新装应用自动重定向：在设置中开启后安装新应用，模块会按匹配到的模板自动写入重定向配置，可在应用配置页复核结果。
- WebUI 备份还原：进入 WebUI 设置页，使用备份导出配置文件，使用还原选择该文件导入。
- WebUI 运行时控制：在 WebUI 设置页切换对应开关，无需重启即可生效。
- 管理界面缩放：在设置页调整界面缩放滑块，App 与 WebUI 同步应用该比例。

### 注意事项

- 更新模块后需要重启设备，使 Zygisk、系统媒体进程和挂载状态完整加载新版本。
- 重启后建议确认已配置应用的保存位置、公共媒体写入结果和文件监视记录符合预期。
- 开启新装应用自动重定向后，新安装的应用会立即按模板生效，如需人工确认请先关闭该开关。

## App 更新

### 修复了什么问题

- 修复日志导出链路，导出记录完整、进度实时显示且不再倒退，KernelSU 环境下的 WebUI 日志包导出同样可用。
- 修复更新检查，改用静态更新清单并在主源不可用时自动切换镜像源，版本信息以模块版本为准，模块更新后会提示待重启状态。
- 修复 WebUI 二级页面滚动、返回与配置交互，输入弹窗居中显示并避让输入法，不再出现动画闪烁。
- 修复界面缩放与窄屏适配下的横向溢出、状态标签竖排、标题裁剪和卡片压缩问题。
- 修复深色模式与主题效果的显示问题，统一对话框与页面背景，消除 WebUI 深色模式下的白色光斑。
- 修复无 root 环境下命令执行失败时的界面兜底提示。
- 修复液态玻璃背景在特定场景下的递归采集崩溃，并区分材质模糊与液态玻璃两种效果。

### 增加了什么功能

- 新增 App 内检查更新入口。
- 新增日志页面下拉刷新。
- 更新弹窗新增按模块、App 与其它分类展示的更新日志。

### 新功能怎么使用

- 检查更新：在 App 关于页点击检查更新，即可获取最新版本信息与更新日志。
- 日志页面下拉刷新：在日志列表顶部下拉即可重新加载最新记录。
