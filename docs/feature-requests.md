# 功能建议跟踪（Feature Requests）

本文件公开跟踪来自 Issue 的功能建议及其处理进展，便于报告者与用户了解每条建议的当前状态与结论。

## 状态定义

| 状态 | 含义 |
| --- | --- |
| 待评估 | 新登记条目的默认状态，尚未给出结论 |
| 计划中 | 已决定实现，尚未随版本发布 |
| 暂缓 | 有价值但当前不做；备注注明重启评估的条件或时点 |
| 已实现 | 已随版本发布；备注注明版本与对应 commit |
| 不考虑 | 明确不实现；备注说明理由（设计边界、与既有功能重叠等） |

## 维护说明

- 编号 `FR-NNN` 全局递增、不复用；
- 「来源」为 Issue 或评论的永久链接，可直达讨论上下文；
- 状态变更在「备注」追加原因与决策日期，不删除历史记录；
- 建议实现发布后，在「备注」回填版本与 commit，并在对应 Issue 中回复建议者；
- 「不考虑」条目的理由写在备注；需要展开设计依据时在对应 Issue 中讨论；
- 欢迎在 Issue 中继续提出功能建议，会登记到本表统一跟踪。
